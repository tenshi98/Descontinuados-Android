# Descontinuados Android
Conjunto de proyectos para android, probablemente no funcionen ya que estaban hechos para funcionar con android 4 al android 6 (el mas nuevo en ese momento) y con librerias que en este momento dudo que todavia existan.

## Uso 🚀
Verificar si los proyectos son para android studio o no, ya que algunos de estos fueron hechos con dicha plataforma, otros fueron hechos con la plataforma netbeans.

Es 100% seguro de que todas estas aplicaciones no funcionen, ya que la mayoria eran app que requerian conexion a internet y una validacion de usuario registrado para acceder a la pantalla principal, y la empresa que hizo estas app hace rato las elimino o dejo de dar el servicio, por lo que les recomiendo solo revisar los proyectos y ver si les sirve algo para sus proyectos.
